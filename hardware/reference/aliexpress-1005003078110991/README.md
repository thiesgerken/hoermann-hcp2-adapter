# 6P6C-HCP-Buchse

Originalangebot: <https://de.aliexpress.com/item/1005003078110991.html>

AliExpress-Artikel `1005003078110991` bietet rechtwinklige THT-Modularbuchsen der 95001-artigen Bauform in mehreren Kontaktvarianten an. Für dieses Projekt ist ausschließlich die ungeschirmte Variante **6P6C** mit SKU `14-200004891` ausgewählt. Die Varianten 4P4C, 6P4C, geschirmte 6P6C und 8P8C gehören zum selben Angebot, sind aber nicht vorgesehen.

## Verwendung im Projekt

J1 verbindet die Trägerplatine mit dem Hörmann-HCP2-Bus. Die elektrische Zuordnung ist GND, GND, B-, A+, +25 V, +25 V. Pinfolge, Gehäusezapfen und Lochbild müssen trotzdem am gelieferten Teil bestätigt werden.
