# 120-Ohm-Widerstand

Originalangebot: <https://de.aliexpress.com/item/1005007375826162.html>

AliExpress-Artikel `1005007375826162` bietet Packungen mit 50 axialen Metallfilmwiderständen in zahlreichen Widerstandswerten an. Gekauft wurde die Variante **120 Ohm, 1 W, 1 Prozent**.

## Verwendung im Projekt

Der Widerstand ist ein loses Ersatz- und Messteil. Er wird nicht auf der Trägerplatine bestückt und erhält keinen Footprint. Das ausgewählte RS485-Modul soll laut Händler bereits einen 120-Ohm-Abschluss enthalten. Ein zusätzlicher paralleler Abschluss würde ungefähr 60 Ohm ergeben. Vor der Inbetriebnahme wird deshalb stattdessen der Widerstand zwischen A und B am stromlosen Modul gemessen.
