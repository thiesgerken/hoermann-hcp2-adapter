# 6P6C HCP jack

Original listing: <https://www.aliexpress.com/item/1005003078110991.html>

AliExpress item `1005003078110991` offers right-angle through-hole modular jacks in several 95001-style contact variants. This project selects only the **unshielded 6P6C** variant with SKU `14-200004891`. The 4P4C, 6P4C, shielded 6P6C, and 8P8C options from the same listing are not used.

## Project use

J1 connects the carrier PCB to the Hörmann HCP2 bus. The electrical assignment is GND, GND, B-, A+, +25 V, +25 V. Confirm contact order, plastic pegs, and hole pattern on the delivered part.
