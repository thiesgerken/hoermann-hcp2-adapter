# 6P6C patch cable

Original listing: <https://www.aliexpress.com/item/1005005913976427.html>

AliExpress item `1005005913976427` describes an RJ11/RJ12 cable with two 6P6C plugs. Listed lengths were 0.5 m, 1 m, 2 m, 3 m, and 5 m. The vendor describes the wiring as straight-through. The purchased length is not yet recorded.

## Project use

The cable connects the adapter to the HCP2 opener. Before use, verify that both plugs have six contacts, pins 1 through 6 have straight-through continuity, and no contacts are shorted. A crossed telephone cable could swap +25 V and GND.
