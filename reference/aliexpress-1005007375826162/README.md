# 120 Ω resistor

Original listing: <https://www.aliexpress.com/item/1005007375826162.html>

AliExpress item `1005007375826162` offers packages of 50 axial metal-film resistors in multiple values. The purchased variant is **120 Ω, 1 W, 1%**.

## Project use

This resistor is a loose spare and measurement part. It is not fitted to the carrier PCB and has no footprint. The selected RS485 module reportedly includes 120 Ω termination. Another parallel termination would produce approximately 60 Ω. Measure resistance between A and B on the unpowered module before commissioning instead.
